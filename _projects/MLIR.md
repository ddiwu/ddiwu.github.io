In this project, I focus on GPU operator optimization based on MLIR, with an emphasis on automatic generation of high-performance matrix multiplication operators. My work explores how to design and optimize the search space and search strategies for kernel generation, enabling the compiler to efficiently discover performant GPU implementations under different hardware constraints. Through systematic exploration and pruning of the optimization space, this project aims to improve both the efficiency and portability of GPU matrix multiplication kernels.
